#  material.pad

**material.pad** — это современный и легковесный саундпад для Windows, выполненный в эстетике **Material 3 Expressive**. 
Программа создана для стримеров, геймеров и всех, кто любит баловаться со звуками в Discord или в играх.

## ✨ Основные возможности

*   **🔥 Огромная библиотека (5000+ звуков)** — встроенная база популярных мемов, реакций и игровых эффектов с Myinstants. Все звуки подгружаются из сети по клику.
*   **⚡ Мгновенное воспроизведение** — умное кэширование (Prefetch) гарантирует, что звук заиграет в тот же миг, как ты нажмешь на пад.
*   **🎤 Виртуальный микрофон** — встроенная поддержка VB-Cable и других виртуальных устройств. Твои звуки услышат в Discord или игре.
*   **⌨️ Глобальные хоткеи** — привязывай звуки к любым клавишам. Они работают даже когда окно свёрнуто или игра активна на весь экран (F8, F9, F10 для управления плеером).
*   **🎨 Кастомные темы** — настраивай акцентный цвет, меняй фон на видео/картинку, сохраняй и загружай темы в формате `.json`.
*   **📁 Свои звуки** — добавляй аудиофайлы до 25 МБ. Встроенный диктофон позволяет записывать голос прямо с микрофона.
*   **🎛️ Панель «Сейчас играет»** — нижняя панель покажет текущий звук и позволит остановить его одним кликом.

## 🚀 Установка

1.  Перейди в раздел [**Releases**](https://github.com/awesomestrue/material.pad/releases).
2.  Скачай последний файл **`material.pad-Setup.exe`**.
3.  Запусти установщик.
4.  ⚠️ *Windows Defender или SmartScreen могут выдать предупреждение (так как файл без цифровой подписи). Нажми «Подробнее» → «Выполнить в любом случае».*
5.  После установки запусти **material.pad** с рабочего стола.

## 🛠️ Инструкция по использованию

1.  **Добавление звуков:** Нажми кнопку «Добавить звук» в левом верхнем углу или перетащи аудиофайлы прямо в окно.
2.  **Назначение клавиш:** Перейди в **Настройки → Клавиши**. Найди нужный звук и нажми на поле клавиши. Нажми нужную клавишу на клавиатуре. Готово!
3.  **Виртуальный выход:** Открой **Настройки → Аудио**, выбери «Виртуальный выход» (например, CABLE Input). Теперь звуки идут в микрофон.
4.  **Изменение темы:** В настройках выбери цвет или загрузи свой `.json` файл. Можно даже поставить видео на фон.

## 💻 Стек технологий

*   **Electron 32** — десктопный фреймворк.
*   **Vanilla JS & CSS** — чистый интерфейс без тяжелых фреймворков (React/Vue).
*   **Material 3 Expressive** — дизайн-система от Google (адаптация для Desktop).
*   **Web Audio API** — обработка и воспроизведение звука без задержек.
